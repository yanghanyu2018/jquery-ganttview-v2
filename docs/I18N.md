# Internationalization / 多语种

The control includes a lightweight i18n layer. It does not depend on Vue i18n, React i18n or other frameworks.

## Built-in locales

```text
zh-CN Chinese
en-US English
fr-FR French
de-DE German
th-TH Thai
```

Aliases are supported:

```text
zh, en, fr, de, th
```

## Initialization

```js
$('#ganttChart').ganttView(data, {
  locale: 'en-US'
});
```

## Runtime switch

```js
gantt.ganttView.setLocale('th-TH', true);
```

The second argument controls whether the current horizontal viewport should be preserved.

## Custom text override per instance

```js
$('#ganttChart').ganttView(data, {
  locale: 'en-US',
  i18n: {
    text: {
      legendResource: 'Airport Resource',
      legendStatus: 'Operation Status'
    }
  }
});
```

## Register a new language

```js
$.fn.ganttView.addLanguage('es-ES', {
  calendar: {
    monthNameShort: ['ene', 'feb', 'mar', 'abr', 'may', 'jun', 'jul', 'ago', 'sep', 'oct', 'nov', 'dic'],
    dayOfWeekNames: ['dom', 'lun', 'mar', 'mié', 'jue', 'vie', 'sáb'],
    dayOfWeekNamesFull: ['domingo', 'lunes', 'martes', 'miércoles', 'jueves', 'viernes', 'sábado'],
    monthDayFormat: '{day} {month} {year} {week}'
  },
  text: {
    legendResource: 'Recurso',
    legendStatus: 'Estado',
    legendTime: 'Tiempo',
    timeMovePrompt: 'Introduzca la nueva hora; deje vacío para alinear con la cuadrícula.'
  },
  labels: {
    statuses: {
      planned: 'Planificado',
      active: 'Activo',
      delayed: 'Retrasado'
    },
    resourceTypes: {
      gate: 'Puerta',
      checkin: 'Facturación',
      belt: 'Cinta de equipaje'
    },
    timeSources: {
      planned: 'Planificado',
      estimated: 'Estimado',
      actual: 'Real'
    }
  }
});
```

## Business data is not automatically translated

The control translates built-in UI text, calendar labels, legend labels, prompt text and enum labels such as `status` and `resourceType`.

It does **not** translate business data fields such as:

```text
cName, sName, tName, flight number, airline name, gate number
```

These should be provided by the business system if they need translation.

## Recommended airport usage

For a real airport product, keep resource codes stable:

```text
A01, C01-C04, Belt 01, MU5101
```

Translate only UI labels, status labels and explanatory text. This avoids changing operational identifiers between languages.
